Fonctionnalités intelligentes

F1 -- Recherche de logements

Le client peut rechercher des logements selon différents critères : localisation, budget,
nombre de chambres, surface, équipements, disponibilité, etc.

F2 -- Recommandation Client  Logement

Le système analyse le profil et les préférences du client et recommande les logements
les plus compatibles.

Exemple :

        Appartement A  94 %
        Appartement B  87 %
        Appartement C  75 %

F3 -- Recherche de colocataire

Le client peut indiquer qu'il souhaite vivre en colocation et renseigner ses préférences :

     budget ;
     localisation ;
     disponibilité ;
     fumeur/non-fumeur ;
     animaux ;
     niveau de propreté ;
     bruit ;
     horaires ;
     visiteurs ;
     habitudes de vie.

F4 -- Matching Client  Client
Le système compare les profils de deux clients afin d'identifier les colocataires
potentiellement compatibles.
Exemple :

        Sarah  Yasmine  93 % compatible
Le système prend notamment en compte :

     budget ;
     localisation ;
     disponibilité ;
     habitudes ;
     préférences de vie.

F5 -- Matching Binôme  Logement

Après l'acceptation mutuelle de deux clients, un binôme est créé.
Le système combine alors leurs besoins et recherche les logements adaptés aux deux
personnes.
Exemple :
Sarah
Budget : 450 DT

     +

F6 -- Estimation du prix

Le système utilise un modèle de Machine Learning afin d'estimer le prix d'un logement à
partir de ses caractéristiques.
Les caractéristiques peuvent inclure :

     localisation ;
     surface ;
     nombre de chambres ;
     type de logement ;
     équipements ;
     état du logement ;
     etc.

Exemple

Un propriétaire saisit :
Localisation : Ariana
Surface : 100 m²
Chambres : 2
Meublé : Oui
Équipements : ...
Le modèle peut estimer :

        Prix estimé : 850 DT/mois
Cette fonctionnalité peut être utile :

     au propriétaire pour fixer un prix cohérent ;
     au client pour évaluer si le prix demandé semble raisonnable.
F7 -- Détection d'anomalies

Le système identifie les logements dont le prix semble inhabituel par rapport à des
logements similaires.
Par exemple :
Logements similaires à Ariana

Appartement A  750 DT
Appartement B  800 DT
Appartement C  780 DT
Appartement D  820 DT

Appartement E  1 500 DT
Le système peut détecter que le prix de l'appartement E est anormalement élevé par
rapport aux logements comparables.
À l'inverse :
Logements similaires
 800 DT

Annonce :
350 DT
peut également être signalée comme une anomalie nécessitant une vérification.

 Important dans votre rapport : une anomalie ne signifie pas automatiquement qu'une

annonce est frauduleuse. Le système indique simplement que le prix est inhabituel.
On peut donc avoir :

        Prix potentiellement inhabituel -- vérification recommandée.
